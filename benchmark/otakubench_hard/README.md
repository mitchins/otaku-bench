# OtakuBench hard slice (hard-v04.0.1)

An unreleased line-by-line Japanese→English challenge set for the VN screen translator: one line at a time, with up to six earlier lines of history. It is kept separate from the public 200-line ranking and is not pooled with it.

Everything in this folder except this README is git-crypted: sources, references, checks, reviews and tooling. Release notes are in `RELEASE_NOTES.md`. To read them you need the repository key: `git-crypt unlock /path/to/otakubench-git-crypt.key`.
